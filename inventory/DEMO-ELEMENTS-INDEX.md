**Estado:** inventario de descubrimiento basado en la demo pública; no es una lista exhaustiva ni una verificación del panel de controles de Flatsome 3.20.11.

## Cómo usar este índice

1. Tratar cada nombre como una **familia identificada en la demo**, no necesariamente como un único shortcode o widget aislado.
2. Crear una ficha en `widgets/` solo cuando haya información útil para documentar; mantener las opciones no verificadas como pendientes.
3. Para cada elemento, registrar por separado: nombre mostrado en UX Builder, shortcode o estructura serializada, campos/controles, contenido hijo, opciones responsivas, clases/CSS y compatibilidad con WooCommerce.
4. No inventar la sintaxis de shortcodes a partir del nombre del elemento.
5. Para declarar una opción como “Verificado en 3.20.11”, hace falta comprobarla en una instalación de esa versión o con evidencia técnica equivalente y reproducible.
