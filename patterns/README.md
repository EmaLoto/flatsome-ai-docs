# Patrones de página

Los patrones describen soluciones de composición, no garantizan un formato importable.

## Patrones a documentar
- Landing page de servicio.
- Página institucional.
- Home de tienda.
- Archivo de categoría.
- Ficha de producto.
- Página de contacto.
- Página de preguntas frecuentes.
- Página promocional o campaña.

## Plantilla de patrón
Para cada patrón, registrar:
1. **Objetivo de negocio**
2. **Contenido necesario**
3. **Estructura por secciones**
4. **Widget nativo propuesto y evidencia**
5. **Controles confirmados**
6. **Controles pendientes**
7. **Responsive**
8. **SEO y accesibilidad**
9. **Dependencias**
10. **Pruebas de aceptación**

## Reglas
- No incluir nombres de widgets como hechos si no se han verificado.
- Mantener separados el esquema visual y el formato interno del editor.
- No prometer equivalencia visual exacta sin comparación del resultado renderizado.
- Registrar variantes opcionales para evitar que cada página se convierta en una composición completamente distinta.
