# Alcance y versión

## Objetivo principal
Documentar **Flatsome 3.20.11 con UX Builder clásico**. La versión es el objetivo solicitado para el proyecto; la existencia de una función en esa versión solo debe afirmarse cuando haya evidencia adecuada.

## Dentro del alcance
- Elementos nativos disponibles desde UX Builder clásico.
- Controles y opciones visibles en sus paneles.
- Estructura de secciones, filas, columnas y elementos, con nomenclatura confirmada.
- Ajustes de diseño y responsive que se hayan observado.
- Elementos relacionados con WooCommerce y sus dependencias.
- Patrones de composición y recomendaciones de accesibilidad.
- Pruebas manuales reproducibles.

## Fuera del alcance, salvo evidencia explícita
- Inventar un formato JSON/YAML de importación para UX Builder.
- Afirmar que el contenido de una demo pública representa exactamente la versión 3.20.11.
- Tratar opciones de plugins de terceros como parte nativa de Flatsome.
- Atribuir a Flatsome funciones que en realidad pertenecen a WordPress o WooCommerce.
- Prometer compatibilidad universal entre versiones.

## Fuentes y precedencia
1. Instalación real identificada como Flatsome 3.20.11, con capturas o pruebas reproducibles.
2. Archivos oficiales del tema de esa versión, si se dispone de ellos legalmente.
3. Documentación oficial de UX Themes, indicando cuándo se consultó.
4. Demo pública oficial, como evidencia visual limitada.
5. Otras fuentes, marcadas como externas y pendientes de confirmación.

Si dos fuentes se contradicen, registrar la discrepancia y no resolverla por intuición.

## Registro mínimo de evidencia
Para cada afirmación técnica importante, guardar:
- elemento o control;
- valor o comportamiento observado;
- versión exacta;
- fuente;
- fecha de comprobación;
- captura, fragmento o pasos de reproducción;
- resultado: confirmado, parcial o pendiente.

## Convención de nombres
Usar primero el nombre exacto visible en la interfaz en inglés o español, según la instalación observada. Añadir una traducción explicativa sin sustituir el identificador original.
