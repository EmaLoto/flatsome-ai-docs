# Checklist de validación

## Entorno
- [ ] Se confirmó la versión exacta de Flatsome.
- [ ] Se confirmó que el editor es UX Builder clásico.
- [ ] Se registró la versión de WordPress.
- [ ] Se registró la versión de WooCommerce, si corresponde.
- [ ] Se anotaron los plugins que pueden alterar el resultado.

## Widget
- [ ] El nombre coincide exactamente con la interfaz.
- [ ] Se registraron las pestañas y controles disponibles.
- [ ] Se probaron los valores relevantes.
- [ ] Se comprobó el valor por defecto antes de cambiarlo.
- [ ] Se registraron las restricciones y dependencias.
- [ ] Se adjuntó evidencia suficiente.

## Diseño y responsive
- [ ] Se probó en escritorio.
- [ ] Se probó en tablet o un viewport equivalente.
- [ ] Se probó en móvil.
- [ ] Se comprobaron textos largos y ausencia de imágenes.
- [ ] Se comprobaron enlaces y botones.
- [ ] Se revisaron contraste, foco, etiquetas y textos alternativos.

## WooCommerce
- [ ] Se probaron productos simples y variaciones cuando corresponda.
- [ ] Se comprobó disponibilidad y estados sin stock.
- [ ] Se comprobó el flujo de compra en un entorno de prueba.
- [ ] Se anotaron las dependencias de configuración y plugins.

## Documentación
- [ ] Cada afirmación técnica tiene nivel de evidencia.
- [ ] Los puntos desconocidos están marcados como pendientes.
- [ ] No se inventó sintaxis de importación/exportación.
- [ ] El patrón se describe como conceptual o probado, según corresponda.
- [ ] Se anotó la fecha de última comprobación.
